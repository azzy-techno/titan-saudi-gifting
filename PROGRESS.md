## Decisions
| # | Decision | Reason |
|---|---|---|
| D1 | Textures as WebP, not KTX2 | `toktx` not installable via winget; brief's stated fallback |
| D2 | Scaffold Next.js manually (no create-next-app) | create-next-app refuses non-empty dir |
| D3 | Persistent `<Canvas>` in ROOT `app/layout.tsx` (`StageMount`), locale content in `app/[locale]` | Root layout shared by `/en` and `/ar` → soft navigation, WebGL survives the language switch (unmount debounced 800 ms) |
| D4 | `<html lang/dir>` for `/ar` via inline head script + post-build HTML rewrite; `suppressHydrationWarning` on `<html>` | Root layout cannot read child params |
| D5 | Watch generated by parametric Python scripts (`blender/scripts/`) via Blender MCP | Reproducible; official CAD can replace the GLB later |
| D6 | Fonts: Latin via `next/font/local`, Arabic via plain `@font-face` in `public/fonts` (preloaded on `/ar` only) | Brief: self-host + preload; avoids preloading Arabic on English pages |
| D7 | Type pairing C "Gazette" (Boska / General Sans / IBM Plex Mono / Alexandria / IBM Plex Sans Arabic) | Independent critic ranked C 37/50 vs B 29, A 28; Instrument Serif judged an AI-site cliché; General Sans replaced Geist (Next default) per critique |
| D8 | Fontshare fonts shipped **unmodified** (no subsetting) | ITF FFL v2.0 §02 forbids subsetting/format conversion |
| D9 | Engraving uses OFL faces only (IBM Plex Sans / Plex Sans Arabic) | FFL §02 forbids offering Fontshare fonts for visitor-generated content |
| D10 | Arabic digits rendered from Alexandria via `unicode-range` | IBM Plex Sans Arabic draws ٠ as a dash at HUD sizes (tested, `qa/qc1/type/arabic-digits.png`) |
| D11 | Lead adapter defaults to **mailto** | Only path that reaches a human without backend config; Zoho/API modes wired for later (C2/C3) |
| D12 | `pnpm patch` @react-three/fiber 9.8.1: replace `THREE.Clock` with an identical shim | three r183+ logs a deprecation warning for Clock → breaks "zero console warnings" |
| D13 | `gl.debug.checkShaderErrors = false` in production | ANGLE/D3D compiler info logs (X4122) are warnings, not errors; keeps the console clean |
| D14 | Model availability from `public/models/manifest.json` (not a HEAD probe) | A missing GLB would log a 404 console error |
| D15 | Reduced motion = static representative pose per chapter on a canonical virtual timeline + canvas crossfade; pinned sections collapse to auto height; collections strip becomes a grid | Brief §9.1: no scrubbed camera flights, chapters crossfade |
| D16 | Collection images rendered in their own pass AFTER post-processing | Official product imagery must never be tone-mapped/blurred |
| D17 | Vertical + horizontal lens shift (projection matrix) per camera key; mirrored for RTL | Keeps the watch in a deliberate band beside/above copy (esp. phones) without changing perspective; matches Blender shift for posters |
| D18 | Anatomy labels as two staggered callout rows below the exploded stack (technical-drawing style) | Side columns collided with the intro copy |
| D19 | HUD, labels, captions all DOM; projected from 3D anchors | Reference-site lesson: canvas-baked labels clip and overprint copy |
| D20 | Gear train at true ratios, playback slows to ~1/7 in the movement dive | "Time slows as you look closer" — escapement becomes readable; ratios stay true |
