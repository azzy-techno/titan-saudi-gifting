## Decisions
| # | Decision | Reason |
|---|---|---|
| D1 | Textures as WebP, not KTX2 | `toktx` not installable via winget; brief's stated fallback |
| D2 | Scaffold Next.js manually (no create-next-app) | create-next-app refuses non-empty dir (BRIEF.md, brand/) |
| D3 | Persistent `<Canvas>` lives in ROOT `app/layout.tsx`; locale content in `app/[locale]/layout.tsx` | Root layout is shared by `/en` and `/ar`, so switching language is a soft navigation and the WebGL context survives |
| D4 | `<html lang/dir>` for `/ar` set by an inline head script + a post-build HTML rewrite; `suppressHydrationWarning` on `<html>` | Root layout cannot read child params; this keeps the Canvas persistent AND gives crawlers correct `lang="ar" dir="rtl"` |
| D5 | Watch is generated by a parametric Python script (`blender/scripts/`) run through the Blender MCP | Reproducible, versionable, tweakable; official CAD can replace the GLB later |
| D6 | Fonts self-hosted via `next/font/local` (Fontshare zips from api.fontshare.com; Google OFL fonts via @fontsource packages) | Brief: self-host, subset, preload, swap; next/font adds metric fallbacks (CLS) |
