## Design decisions (geometry)
- Watch space = Blender space (Z up = dial normal, +Y = 12h, +X = 3h), 1 BU = 1 mm. Camera "up" for cameras.json shots = watch +Y (12 o'clock up), not specified in the contract -> assumed and logged here.
- Z stack used (mm): crystal apex +4.20, crystal edge top +3.60, bezel top +3.40 (bezel 2.4..3.4, visible width 2.18 mm: outer r 19.50, bore r 17.32 = crystal), case top face +2.40 with 0.5 mm 45deg polished chamfer, hands seconds +1.6 / minute +1.1 / hour +0.7, indices 0..+0.5, dial -0.4..0, mainplate -0.6..-1.5 (+ rim to -3.6), wheel layers L1 -1.75, L2 -2.15, L3 -2.55, L4 -2.93, balance rim -3.1..-3.45, hairspring -3.6, bridges -3.6..-4.15, rotor -4.35..-4.98, case bottom -5.40, caseback medallion face -6.80. Total 11.0 mm.
- Gear train layout (watch XY, mm), centre distances exactly per spec modules: centre C(0,0); third T = 5.40 @ -35deg; fourth F = T + 4.675 @ -110deg; escape E = F + 4.095 @ 165deg; pallet arbor P = E + 2.80 @ 180deg; balance W = P + 4.00 @ 180deg; barrel B = 5.88 @ 120deg. Meshing pairs share Z: barrel teeth/centre pinion, centre wheel/third pinion, third wheel/fourth pinion, fourth wheel/escape pinion, escape wheel/pallet stones. Wheels that overlap in plan sit on different layers; no wheel disc covers another arbor; everything inside r 15.
- Case + lugs built as ONE watertight mesh from a 2D signed-distance outline (circle r 20.5 smooth-unioned with tapered lug quads, strap gap 20.2 mm subtracted with small fillets) -> marching squares -> profile sweep (polished chamfer + micro-rounds, slight flank draft) -> CDT-triangulated caps with interior points -> lugs bent down by a smooth height function. Rehaut/movement holder/caseback seat are a revolve joined into the same mesh.
